# ExerciseItem

An exercise in the reader Exercises tab: kind (Explain from memory, Apply, Calibrate, Experiment, Connect), prompt and answer area.

- Provide `n`, `kind`, `prompt` and, while open, the work area as `children` (`TextField` multiline + `Button`). Once done: `done`, `answer` and `time`; the meta row shows "Done".
- The Exercises tab hides the source text and the note panel: answering from memory is the point. Comparing with the source comes only after submit.
