# ExerciseItem

Um exercício na aba Exercícios do leitor: tipo (Explicar sem consultar, Aplicar, Calibrar, Experimento, Conectar), enunciado e área de resposta.

- Forneça `n`, `kind`, `prompt` e, enquanto não estiver feito, a área de trabalho como `children` (`TextField` multiline + `Button`). Feito: `done`, `answer` e `time`.
- A aba Exercícios esconde o texto e o painel de notas: responder de memória é o ponto. "Comparar com o texto" só depois de enviar.
