# Button

O botão. `secondary` é o padrão; `primary` (norte) no máximo uma vez por região, para a coisa que a página existe para fazer.

- Forneça `children` começando por verbo, em sentence case: "Começar revisão".
- `icon` opcional à esquerda (`play`, `plus`, `check`, `arrow`, `lock`); nunca só ícone em ações principais.
- `ghost` para ações terciárias dentro de listas e barras. `size="sm"` (30px) só em linhas densas.
- O rótulo do primary usa `on-norte`; o foco é `focus-ring`.
