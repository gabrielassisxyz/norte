# Button

The button. `secondary` is the default; `primary` (`norte`) at most once per region, for what the page exists to do.

- Provide `children` starting with a verb, in sentence case: "Start review".
- `icon` is optional on the left (`play`, `plus`, `check`, `arrow`, `lock`); never icon-only on main actions.
- `ghost` for tertiary actions inside lists and bars. `size="sm"` (30px) only in dense rows.
- The primary label uses `on-norte`; focus is `focus-ring`.
