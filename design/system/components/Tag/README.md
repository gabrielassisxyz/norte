# Tag

Assuntos e tags. `topic` é um assunto (área ampla, preenchido em `sunken`); `tag` é uma etiqueta livre, com `#` em `muted`.

- Forneça o texto em minúsculas para tags, sentence case para assuntos.
- `active` (filtro aplicado) usa `norte-soft` com texto `norte`. `count` mostra quantos itens, em mono.
- Com `onClick` vira botão (filtro). Nunca multicolorido: tags não têm cor própria.
