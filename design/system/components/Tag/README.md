# Tag

Topics and tags. `topic` is a topic (a broad area, filled with `sunken`); `tag` is a free label, with `#` in `muted`.

- Use lowercase for tags, sentence case for topics.
- `active` (applied filter) uses `norte-soft` with `norte` text. `count` shows how many entries, in mono.
- With `onClick` it becomes a button (filter). Never multicolor: tags carry no color of their own.
