# SyncStatus

Estado local-first, pequeno e discreto. Um ponto colorido mais a palavra; nunca só o ponto.

- `state`: `saved` (padrão), `syncing`, `offline`, `conflict`. `label` substitui o texto padrão.
- Fica na barra do app ou no `meta` do `PageTitle`. Conflito é o único estado que pede atenção (`danger`).
